# User Dashboard

A responsive User Dashboard built using React, TypeScript, and useReducer for centralized state management.

## Features

- Add User
- Edit User
- Delete User
- Search Users
- Sorting
- Pagination
- Form Validation
- Responsive Design
- Loading Animation
- Local Storage Persistence

## Technologies Used

- React
- TypeScript
- CSS
- useReducer

## Run Project

```bash
npm install
npm start
